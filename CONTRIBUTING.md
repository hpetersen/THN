# Contributing to THN

Thanks for helping! Bug reports, ideas and pull requests are all welcome.

## Contributor License Agreement

Before a pull request can be merged, you need to sign the
[Contributor License Agreement](CLA.md) once. You keep the copyright to your work; the CLA
lets the maintainer include it in every distribution of THN, including the App Store
version. A bot comments on your first pull request with instructions: reply with

> I have read the CLA Document and I hereby sign the CLA

## Pull requests

- Keep changes focused; one feature or fix per pull request.
- Match the existing style: SwiftUI, no third-party dependencies, the newspaper design
  language in `Theme.swift` and `PaperChrome.swift`.
- Build and run on a device or simulator before opening the pull request, and describe how
  you tested it.

## Issues

Open an issue for bugs (with steps to reproduce, device and iOS version) or feature ideas.
